# Ting's Reading Notes

Personal reading notes hosted as a static site via GitHub Pages.

## Live site

Published from the `main` branch (root), so changes appear only after merging into `main`.

- Home — https://itinghung.github.io/reading-notes/
- *Chip War* — https://itinghung.github.io/reading-notes/chip-war-notes/
- *Nexus* — https://itinghung.github.io/reading-notes/nexus-notes/

Viewing `.html` files on github.com shows source, not the rendered page. To preview locally, run
`python3 -m http.server` in the repo root and open http://localhost:8000.

## Structure

- `index.html` — homepage listing all books
- `notes.css` — shared stylesheet
- `assets/` — images and other design assets
- `chip-war-notes/` — notes for *Chip War*
- `nexus-notes/` — notes for *Nexus*
- `styling-notes.md` — style guide and shared component usage
